# U-20260919-01：有人在旁的無人流程試跑（商店分頁盤點）

目的：驗證 Pico 護欄與無人流程本身，順便收集商店分頁截圖（P3 價格清單用）。操作者在電腦前監看。

- 開關：不改任何伺服器開關，也不重啟伺服器。
- 不花遊戲幣、不買東西、不換裝。

## 起點
大廳（`shots/shot-215206.png` 那個畫面）。遊戲視窗在主螢幕，英文輸入法。

## 步驟
1. `session start "U-20260919-01 shop tabs"`，拍一張起點截圖，確認是大廳。
2. 點「商城／格納庫」（視窗座標約 615,90），等 2 秒後截圖。預期：進入商城或格納庫畫面。
3. 從截圖找出分頁的位置。每個分頁都「點一下 → 等 1 秒 → 截圖」。預期：每次換分頁，清單內容都會改變。
4. 點「上一頁」（約 1560,90）回大廳，截圖。預期：回到大廳。
5. **故意觸發停止條件**（請操作者配合）：我會先請你點一下 VS Code，再送一個 `KEY ESC`。預期：BLOCKED，session 轉成 halted，這個按鍵沒有送出。
6. `session end`。
