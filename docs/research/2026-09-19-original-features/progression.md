# 帳號成長：軍階、經驗、獎勵、機體取得、教學（外部資料，🟡 中階整理，待審）

可信度標籤：**官方**＝營運商公告或官網說明；**玩家實測**＝玩家自己量測，有數字或截圖；**玩家說法**＝玩家轉述，未驗證。
三個版本的規則不完全一樣。本專案重現的是台版，但台版官方資料留下的很少，所以大量引用韓版（Netmarble／GameHi）和日版（Nexon 鉄鬼）的資料，每條都註明是哪一版。

## 1. 軍階階梯

- **日版完整階梯**（官方，JP-CLASS）：訓練兵 → 二等兵 → 一等兵 → 上等兵 → 兵長 → 伍長（1～5号俸） → 曹長（1～5号俸） → 軍曹（1～5号俸） → 少尉（1～6号俸） → 大尉（1～6） → 中尉（1～6） → 少佐（1～6） → 大佐（1～6） → 中佐（1～6） → 准將 → 少將 → 中將 → 大將 → 元帥。
  - 原網頁的順序就是這樣（大尉排在中尉前、大佐排在中佐前），照抄；是否排版錯誤 ⬜。
- **韓版名稱**（官方，KR-F13 表格）：사병（이등병、일병、상병、병장）→ 부사관（하사、중사、상사）→ 위관（소위、중위、대위）→ 영관（소령、중령、대령）。有 **호봉**（俸級）作為軍階下的小階（KR-U11、KR-F62「하사 1호봉/2호봉/3호봉」）。
- **台版名稱**（玩家說法）：訓練兵、二等兵、一等兵、上等兵、班長、下士、中士、上士、少尉、中尉……。下士以上才有「幾階」：「下士1階升2階」（BH-1738、BH-1741、BH-1758）。「二等、一等、上等、班長、下士、中士等等，都是算一個階段，幾階幾階是不會送獎勵的」（BH-1738 留言）。
- 台版官網個人頁有軍階圖示檔名 `gl_2_48_s.gif`（TW-PILOT）→ 推測圖示編號最多到 48 以上 🟡 [GUESS]。
- **門檻經驗值**：三個版本都沒找到。韓版軍階頁（KR-CLASSG）整頁是圖片，Wayback 沒存到。⬜

## 2. 晉升獎勵

- **韓版晉升獎勵點數**（官方，KR-F13 表格；2009-03-03 起實施，KR-U11）：

  | 軍階 | 點數 |
  |---|---|
  | 이등병 | 1,500 |
  | 일병 | 3,000 |
  | 상병 | 10,000 |
  | 병장 | 10,000 |
  | 하사／중사／상사 | 各 20,000 |
  | 소위／중위／대위 | 各 20,000 |
  | 소령／중령／대령 | 各 20,000 |

  - 獎勵放在遊戲內的「선물함」（禮物箱），領出後在倉庫的「아이템」分頁使用。**호봉（小階）上升不發點數**（官方，KR-U11）。
- 韓版 2009-03-10 起，**호봉 每升一級發 5 張卡片優惠券**（官方，KR-F15）。
- 韓版 2009-12-03 시즌2：「훈장 지급 및 호봉 진급시 포상 삭제」，勳章獎勵和小階晉升獎勵都取消（官方，KR-F63）。
- **台版**：
  - 玩家整理的晉升獎金是「1500 3000 5000 10000 20000」（玩家說法，BH-1758）。
  - 「少尉升中尉會送兩萬」（玩家說法，BH-1758）。
  - 升上士送 2 萬（玩家說法，BH-1741）。
  - 「生等送1W」（玩家說法，BH-1933）。
  - 獎勵經由**信箱**領取（玩家說法，BH-1738、BH-1816）。台版稱之為「退休慰問金」信件（BH-1816）。
  - **與韓版有衝突**：台版玩家列出 5000 這一級，韓版表格沒有。兩個版本並列，台版以玩家說法為準，未驗證。
- **台版新帳號初始 G 幣**：
  - 「一開始有3W」（BH-1732）；「新手就有3萬了」（BH-1721）；「一開始的5W」（BH-1933）。都是玩家說法，互相矛盾。
  - 韓版 2009-01-20 發給全部玩家 3 萬點（官方，KR-U4 的下一篇，見 economy.md）。

## 3. 機體取得（基本 8 機種）

- **韓版 OBT 初期**：8 個兵種一開始全部可用（官方，KR-F62：「기존에 8개의 병과가 처음부터 다 주어졌다면」）。訓練兵、이등병有預設武器（官方，KR-U7「계급별 디폴트 아이템 착용」）。
- **韓版 시즌2（2009-12-03）以後**：依軍階和教學發放（官方，KR-F62 表格；KR-F63「기존 유저분은 해당 사항이 안됩니다」）：

  | 兵種 | 條件 |
  |---|---|
  | 소형（輕量） | 完成소형教學 |
  | 강습（強襲） | 升이등병 → 完成강습教學 |
  | 저격（狙擊） | 升일병 → 完成저격教學 |
  | 정비（整備） | 升상병 → 完成정비教學 |
  | 공병（工兵） | 升병장 |
  | 중형（重裝） | 升하사 1호봉 |
  | 화력（火力） | 升하사 2호봉 |
  | 관측（偵測） | 升하사 3호봉 |

- **韓版 2010-01**：改成自選，每升一個軍階還是只能領一台（官方，KR-F70）。
  - 훈련병～상병：從 소형／강습／저격／정비 中選。
  - 병장～하사 3호봉：從 공병／중형／화력／관측 中選。
  - 流程：完成某機種的教學後，會跳出「要領取這台嗎」；按取消就能改做別台的教學再領。
- 韓版 2010-04-30～05-31 有「기체 라이센스 획득권」活動（官方，KR-F88）：
  - 限상병以下，8 台中選 1 台，每人限 1 次。
  - 用了就等於取得該機體。之後在機體發放階段**不會再多拿一台**。
  - 這是現金和點數都買不到的特殊道具。
- **台版**：
  - 基本 4 台（輕量、強襲、狙擊、整備）靠升級領，要在教學模式考照（玩家說法，BH-1933、BH-1780、BH-1840）。
  - 另外 4 台（重裝劍虎、火力聖戰士、工兵雷霆、偵測觀星者）在 2011-03-03 改成 G 幣商城買執照（官方，見 tw-2011-03-03-patch.md）。
  - 「升級後領取的機種次數可以儲存，從新兵存到班長可直接領4台進階機種」：2010-10 CB 時期的說法（玩家說法，BH-G67）。
  - 「正常來說 升到班長每次升級拿一次 但是台版亂改變成15萬買一張進階駕照」（玩家說法，BH-1752）。
  - 「要兩個執照獲得機會才能得到」（玩家說法，BH-1975）。
  - 「商城買未到階的執照後 想領系統發的執照就不能領了」（玩家提問，BH-2082，沒有人回答）。
  - 「下士一階…4台車…要系統允許免費執照達到贈送第5台車」（玩家提問，BH-1719）→ 台版可能也有第 5 台以上的免費執照，⬜。
- **台版考照失敗的錯誤碼**（玩家實測，有截圖文字，BH-1780）：做完教學後跳出「無法取得執照」，按 more 顯示 `[Code:0x00260112] [Origin:0x0201] [Error:0x00AD0113]`。回覆說「這算是台服目前的既定BUG了」。
  - **對本專案**：`0x00260112` 可以對照客戶端 dispatcher，查是不是教學結束後取得執照的回應 opcode。⬜ 未對照 DLL。

## 4. 教學（튜토리얼）與訓練模式

- **韓版教學**：2009-07-14 上線（官方，KR-F40）。
  - 大廳最下面的「가이드」→ 選兵種。只有 소형、강습、저격、정비 4 台有教學，由前到後難度遞增。
  - 完成獎勵（官方，KR-F40 表格。網頁上的兵種欄是圖片，下列對應是依武器所屬機種推定 🟡）：
    - 소형：HAR-22 7일、LOM-1 7일、AMRL-5 7일、5000 포인트
    - 강습：MAF-3 7일、MR-4 7일、Su-30 7일、5000 포인트
    - 저격：IFP-40 7일、ARL-3 7일、HWP-9 7일、5000 포인트
    - 정비：GT-V 7일、HW-5 7일、駕駛員「레이첼 베스」7일、5000 포인트
  - 舊玩家做完也拿得到同樣的獎勵。
- **韓版訓練模式**（官方，KR-F49，2009-09-08）：
  - 在商店／倉庫選兵種和武器後按「트레이닝」進入，可選 초/중/고 三種難度。
  - 場內有道具箱（탄보급／내구도 회복），結束時有結果畫面。
  - 2009-12 改成單獨的圓形訓練室，一次帶 1 台機體進去（官方，KR-F60）。
- **日版**：商店的「試射」按鈕會用訓練模式試射選中的裝備（官方，見 economy.md JP-HANGAR）。
- **台版**：
  - 商店購買選單可以「不用花錢試用武器」，只能在測試場用（玩家說法，BH-G67）。
  - 「商城中的練習過了會怎樣?有獎勵嗎?」（BH-2096）沒有人回答。
  - 「教學指導過了可以拿獎勵嗎?」（BH-2097）得到的回覆是「可能你在新手訓練時已經過完 拿完了」（玩家說法）。
  - 「很多人說訓練可以拿到未開放的武器」，進階機體的訓練會送「特級微型火箭彈（主武）、輔助火箭發射器和四連發火箭」（玩家說法，BH-1805）。
  - 用 G 幣買進階機體後，教學顯示「訓練已經通過」，無法再做（BH-1805）。

## 5. 經驗值

- 公式和數值都沒找到。⬜
- 零星資料：
  - 韓版 OBT 時修正過「획득 경험치」和「난입 시 기본 경험치」（中途加入的基本經驗）（官方，KR-U4、KR-U6，見 pvp-modes.md）。
  - 「經驗值算法1600+1600*50%=2400」：看起來是基本值加 50% 加成道具（玩家說法，BH-1767 留言）。
  - 高級協力任務對低軍階的新帳號給的經驗很多，「印想25%還是50%」（玩家說法，BH-1741）。
  - 經驗加成道具：金／紅迷彩 +10% 經驗（官方，見 economy.md）；各種週末經驗加成活動（見 events.md）。
