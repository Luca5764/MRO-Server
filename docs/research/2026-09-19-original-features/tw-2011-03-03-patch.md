# 台版 2011-03-03 改版說明（外部資料）

來源：[OBS] 操作者轉貼巴哈姆特文章（2011-03-02 編輯），內容引用官網公告 `http://mr.wasabii.com.tw/MR_notice/notice_content.aspx?T=3&K=12564`，另外附上日版資料庫整理（巴哈 `bsn=16400&snA=1645`）。這是玩家轉述，不是規格。

## 官方改版內容

1. **新地圖**：

   | 模式 | 地圖 |
   |---|---|
   | 死鬥 | 落日大道 |
   | 憤怒 | 沙坑碉堡 |
   | 殊死戰 | 神聖之鎮 |
   | 爆破 | 北極地帶 |
   | Boss | D-Day |
   | 佔領 | 廢武處理場 |
   | 奪取 | 黃金艙門 |
   | 協力任務 | 援救基地戰 |

2. **新對戰模式**：
   - **BOSS 模式**：至少 8 對 8。一方要在時限內保護 BOSS 護送到目標地點；另一方要閃躲護衛隊和 BOSS 的攻擊，把畫面上方中央的 BOSS 體力打光才算獲勝。
   - **憤怒模式**：至少 16 對 16，持續 1 小時。沒有固定目標，但對戰中會出現突發任務，先完成的一方可以拿到限時特殊效果，例如攻擊力或移動力提升、彈藥無限、回復耐久度。（與 `RAGEMODE_INTRUDE_ONLY` 有關：憤怒模式強制允許戰鬥中參與，見 backlog INTRUDE。）
   - **奪取模式**：限時內奪取敵方物品，先達到目標數值的一方獲勝；時間到則由奪取物最多的陣營獲勝。
3. **卡片系統**：可以對各類型機體抽卡、換卡。卡片分等級，等級越高越難取得。**集滿任一機型的 20 張系列卡**，就能得到該機型的傳奇機體一台。細節見 `research/2026-09-19-card-system/notes.md`。
4. **四張進階機體使用執照**，在 G 幣商城販售：
   - 重裝型「劍虎」
   - 火力型「聖戰士」
   - 工兵型「雷霆」
   - 偵測型「觀星者」
5. G 幣商城調整：新增或調整武器裝備、塗裝、公會相關道具。
6. M 幣商城停止販售，部分商品移到 G 幣商城；「天天贈滿 50M 幣」活動停止。

## 日版資料補充（卡片、傳說機）

- 一套 20 張。一次最少抽 1 張、最多抽 20 張。6 張多餘的卡可以換抽。集滿後按右下角「Legend Bonus」領取；**事先必須擁有該款的普通型機體**。卡片不能交易。
- 傳說機只有輔助性質的提升；血量、攻擊、防禦與普通型相同。數值見 `research/2026-09-19-legend-bonus/notes.md`。這篇的補充：
  - 觀測型：第一階段視界障礙距離 +10 M、第二階段 +20 M。
  - 整備型：另有一說是「修理速度 +20%」，未確認。
- 傳說機的日文名稱（google 翻譯）：
  - 輕量「烏鴉」（Raven）
  - 強襲「屠殺者」（Cruel Massacre）
  - 狙擊「幻象」（Phantom）
  - 重量「女武神」（Valkyrie）
