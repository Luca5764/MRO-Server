## 測試 K：開局壞掉時，到底套用的是不是 GM 按鍵表

不改程式、不改設定檔。

1. 完全重開客戶端，進 PvE，**不要開選項**，先確認左鍵不能用。
2. 看清楚畫面底部的 HUD（血量、彈藥那一列），截圖或記下來。
3. 按 **Scroll Lock** 一次、停一下，總共按 4 次，每次都看畫面有沒有變化（名字、分數、底部列）。
4. 隊伍聊天回報：第幾次按的時候，什麼東西消失了（或完全沒變化）。
5. 之後可以 Esc →選項→取消恢復，再按 Scroll Lock 看看。

判讀：
- 按到第 4 次底部列消失（或其他 HUD 依序消失）→ 開局套用的是 **GM 按鍵表**（`ApplyGMControl`），要查為什麼開局那一刻客戶端認為是 GM。
- 完全沒變化 → 不是 GM 表，是別的原因讓一般綁定失效。
