4. 如果還是不能用，再做一次：Esc →「選項」→ 按鍵設定 → **儲存**，確認能用（跟測試 F 對照）。
5. 隊伍聊天回報。

- 取消就能用 → 修好的是「打開／關閉選項 GUI」，不是 `ApplyControl`。
