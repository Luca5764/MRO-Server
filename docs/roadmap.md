# Roadmap

> 2026-09-18 定案，PM：Fable（高階）。之後排優先序一律以「**兩個人以上能一起打完一場**」為準，不再以「上一輪測試看到什麼壞掉」為準。

## 最終目標

2026 年 11 月中之前，操作者和幾位朋友透過 VPN 連線，一起打完一場 PvE。

- PvP 是延伸目標。
- 經濟系統全部開放。
- 不對外公開，與上游各做各的。

## 里程碑

| 里程碑 | 時程 | 完成條件 |
|---|---|---|
| **M0** 基礎收尾 | 本週（至 2026-09-25） | C1 開關收斂；A6b 回歸測試涵蓋 PvE 整場；X1 例外防護；N0 第二台主機連得到伺服器 |
| **M1** 同房互見 | 第 1–2 週 | 第二個客戶端進入同一個房間，兩邊互相看得到對方，房間聊天互通 |
| **M2** 區網打完一場 | 第 2–4 週 | 區網內兩個人一起打完一場 PvE（開始 → 戰鬥 → 結算 → 回房間） |
| **M3** 遠端朋友 | 第 4–6 週 | 一位遠端朋友透過 VPN 完成 M2 的全部內容。前提：帳號白名單、X1、安裝包 |
| **M4** 延伸：TDM | 第 6–8 週 | 四個人以上打完一場 TDM |

## 工作線

- **A 線（要用客戶端，一次只能做一件）：** C1 → T1 實測 → M1 實測 → M2 實測
- **B 線（不需要客戶端，交給中階平行做）：** A6b、S1、N0、P2、X1
- **C 線（高階自己做）：** D1 多人房間模型設計稿（S1 交付後開始；PM 審查、操作者同意之後才能實作）

任務契約在 `docs/backlog.md`。

## 風險

- **M3：** 朋友的作業系統決定要用哪個 exe：Win11 用修改版，Win10 用原廠版（`reference/setup.md`「依作業系統選 exe」）。**Win7 和 Win8 完全沒有測過。**
- **M2：** PvE 是 P2P（由房主的客戶端開 Listen），加入者直接連到房主的 IP 和埠（`research/2026-09-18-d1-room-formats/`），VPN 和防火牆都要讓這條連線通。
