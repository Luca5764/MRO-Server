## 還沒證明的事，不要跳步

✅ **「log 印的值 ＝ 寫進 `UNetConnection+0x50`（`CurrentNetSpeed`）的值」已機械核對**（未經跨公司審查）。
verifier 反組譯 + 高階逐 byte 覆核，對象是原廠備份
`Engine.dll.bak-netspeed-host-20260922-064503`（sha256 `fc51fe12…`）：

| 位址 | bytes | 指令 |
|---|---|---|
| `0x1047f9c4` | `8b 55 08` | `mov edx,[ebp+8]` |
| **`0x1047f9c7`** | **`50`** | **`push eax`** ← log 的 `%i` 引數 |
| **`0x1047f9c8`** | **`89 42 50`** | **`mov [edx+0x50],eax`** ← 寫 `CurrentNetSpeed` |
| `0x1047f9cb` | `68 44 54 6c 10` | `push 0x106c5444` ＝ 字串 `Client netspeed is %…`（UTF-16LE，file offset `0x003c5444`） |

log 函式是 `0x1047f9d8` 的 `call dword ptr [0x10679210]`
→ `Core.dll!?Logf@FOutputDevice@@QAAXPBGZZ`。
**`push eax` 與 `mov [edx+0x50],eax` 只差一個 byte，中間沒有任何改值指令，是同一個 `eax`**；
兩者都在修補區間 `0x1047f9b1–0x1047f9bc` 之後。
→ 所以那行 log **不是**另一個變數，它就是房主記下的送出預算。

> verifier 另外指出背景摘要（`design.md`）漏列了 `0x1047f9c7` 的 `push eax` 一行，
> 不是矛盾，但 `design.md` 的組語片段該補。
>
> 仍然沿用的既有假設：`+0x50` 就是 `UNetConnection::CurrentNetSpeed`。
> verifier 沒有重新反查型別佈局，這一格是承接前人結論，不是本輪新證。
